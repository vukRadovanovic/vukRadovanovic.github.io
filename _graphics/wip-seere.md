I'm currently working on a renderer written in Rust using the Vulkan library.  As is usually the case with Vulkan, it's taking a little while to get things up and running, but stay tuned - I'll update this page as I reach important milestones, like actually seeing a triangle on my screen. :)

For now, here are some links to the resources I'm been deeply exploring in my development journey.
- [How To Vulkan in 2026](https://www.howtovulkan.com/) by Sascha Willems, my current primary source to help me get up and running.
- [Are we game yet?](https://arewegameyet.rs/) A comprehensive list of Rust crates for game engine development.  I am trying to keep the project as light on dependencies as possible, however.
- [NVIDIA Vulkan Ray Tracing Tutorials](https://nvpro-samples.github.io/vk_raytracing_tutorial_KHR/) Though I'm developing on my AMD card (9070 XT), these tutorials will prove useful once I start the conversion to a path tracing renderer.


This project will be my first delve into both the language and the graphics API, so it'll be a learning experience on multiple fronts.  I expect quite a few challenges along the way, but I'm having a ton of fun so far.

It'll also serve as a way for me to exercise thoughtful, deliberate use of LLM tools.  It's impossible to avoid the influence of these technologies in our daily lives, and almost as difficult to resist the allure of increased productivity with a fraction of the effort.  However, I find that it's been increasingly important to my mental health that I have a number of outlets through which I can avoid letting my brain slip into atrophy.  This project is one such outlet.

My pledge to myself is to use LLMs only as a learning tool, essentially as a focused natural-language documentation search when a manual search can't turn up what I'm looking for.  Anything that touches more than a single line of code is doing too much.
